# Saran V — Full 3D Developer Portfolio

Premium immersive 3D portfolio for **Saran V**, Junior Full Stack Developer.

## 3D Effects Throughout

| Section       | 3D Feature                                      |
|---------------|-------------------------------------------------|
| Hero          | Floating geometric shapes (R3F + distortion)    |
| About         | Interactive 3D Flip ID Card with photo          |
| Skills        | 3D Tilt cards on mouse hover                    |
| Projects      | 3D Tilt project cards with depth                |
| Experience    | 3D tilted timeline card + certificate cards     |
| Education     | 3D depth cards                                  |
| Global        | Ambient floating orbs, glassmorphism, shadows   |

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
